# 领主

你是领主。交易傀儡替你卖货，务农傀儡替你种地，士兵替你守营、巡逻和跟随。

适用于 Minecraft Java 版 **26.3**、Fabric Loader **0.19.5**、Fabric API、Java **25**。

模组在列表里的名字是**领主**。内部 id 仍是 `trading_golem`，已有世界里的箱子和傀儡不用改。

## 交易傀儡

### 召唤

把**雕刻过的南瓜**或**南瓜灯**放在**绿宝石块**顶上。

- 绿宝石块变成一只**交易箱子**，南瓜被消耗。它不是普通箱子，外观是深绿木箱配金绿锁扣。
- 箱子旁边（或南瓜原来的位置）出现一只交易傀儡，并记住这只箱子。
- 箱子朝向和南瓜一致。
- 挖掉交易箱子，傀儡会一起消失，身上的货掉在脚边，箱子里的东西照常掉出来。把交易箱子再放下去，会再生成一只傀儡。

创造模式物品栏的刷怪蛋也能生成傀儡。蛋生出来的傀儡没有绑定箱子，会认附近 12 格内最近、还没有主人的箱子。

### 它会做什么

1. 走到自己的箱子旁，拿走一叠**不是绿宝石**的物品。绿宝石留在箱子里，当作已经赚到的钱。
2. 在大约 48 格内找正在收购这件东西的村民（对方给出绿宝石，交易次数还没用完，数量也够）。
3. 走到村民**脸前的过道**上就卖。格子里的村民四周挡住脚、只有脸前面是空的，也可以隔着那一格成交，不会挤进格子把人放出来。村民站在半砖上、或比过道高几格，也算在范围内。
4. 按村民当前的收购价卖掉。价格里的供需波动会算进去。卖掉的次数会正常消耗，村民之后仍按原版规则补货。
5. 绿宝石先拿在身上，这叠货卖完或卖不掉，再放回箱子。箱子满了就掉在傀儡脚边。
6. 这种货物没人收，就放回去，换箱子里的下一种。全部都卖不掉时，等 15 秒再重试。

正在和玩家交易的村民、幼年村民、睡觉的村民会被跳过。

傀儡不会自己走丢。交易箱子被挖掉时它会消失；把这只箱子再放下，会重新生成一只。普通箱子它不认。

## 务农傀儡

### 召唤

把**雕刻过的南瓜**或**南瓜灯**放在**小麦块**顶上。

- 小麦块变成一只**农作物箱子**，南瓜被消耗。外观是干草色木箱配绿锁扣。
- 箱子旁边出现一只务农傀儡，并记住这只箱子。
- 挖掉农作物箱子，傀儡会一起消失。把箱子再放下去，会再生成一只。

### 它会做什么

小麦块直接放在中心地面上。箱子替换小麦块后，就坐在这一格上；沟和耕地都在箱子下面那一层，箱子正下方的方块不挖、不耕。

以这一格为中心，横向和竖向都隔着 4 格，顺着 **11×11 的边**绕圈挖。四边正中各留一格当过道，人可以从过道走进去。水只放在四个角，顺着沟流到过道跟前。

1. 走到箱子旁，拿走一把铲子，从角上起顺时针把沟挖掉，掉落放回箱子。石头这类必须用镐的方块会留着。
2. 拿走水桶，往四个角灌水。空桶放回箱子；四个角还没灌完，就再拿下一桶。
3. 拿走锄头，把内部 9×9（箱子正下方除外）耕好。粗泥和缠根泥土会先变成泥土，下一轮再耕。
4. 从箱子里随机拿一种能种在耕地上的作物（小麦、甜菜、胡萝卜、马铃薯、西瓜、南瓜、火把花、瓶子草），种下去。西瓜和南瓜不种在离中心的 x 距离为偶数的格子上，这些格子留空给果实。
5. 作物成熟后收掉，产物放回箱子，再从箱子里拿种子补种。

铲子、锄头和水桶都从这只箱子里拿，用完或换下一件事时放回去。箱子里没有对应工具时，它会在旁边等，你放进去后会继续。

## 士兵

士兵是一种村民职业。一个士兵箱子只收一名士兵。放置箱子的人是领主。

### 招募

合成**士兵箱子**：金块在上，左右各一块铁块，下面是皮革、箱子、皮革。配方用的是金块和铁块，不是锭。

放下士兵箱子后，让一名村民把这只箱子当成工作站点。他会变成士兵，外貌是村民的脸和袍子，骨架和玩家一样，所以盔甲、武器和马鞍的位置都对。

第二名村民如果也来认这只箱子，会被退回无业，原来的士兵继续占着站点。

### 界面

右键士兵，三个标签：

- **信息**：领主、村民等级和经验、营地还缺什么。
- **指令**：休整、巡逻、跟随防御、跟随进攻；武器选近战、远程或自由；骑马开或关。
- **物品栏**：士兵身上的装备和背包。盾放在副手。盾不是必装。

这些选择记在箱子上。默认是休整、自由选择武器、不骑马。

### 营地

士兵第一次上工前先建营。营地以箱子为中心，一共三层：箱子这一层是走道，下面是 **7×7 的石头**，上面清出一人高。床在箱子的西北，床头朝西。木围栏栓马桩在东南。坐标按世界方向算，不跟箱子的朝向转。

材料从箱子里拿：石头（只认原版石头）、任意床、木围栏，以及清方块用的镐和铲。掉落放回箱子。士兵箱子本身不会被拆。信息页会列出还缺的东西。营地第一次建完后，指令会被设成休整。之后只有休整时才修补营地。

### 指令

- **休整**：把武器、盔甲、箭、食物拿全。箱子里有盾就装备，没有就空着手。自己吃饭。向附近村民买补给，不买金苹果和金胡萝卜。栓着的马没满血时，用小麦、干草、苹果或糖喂它，金苹果和金胡萝卜留在箱子里。
- **巡逻**：绕着营地大约 20 格走一圈。看见 12 格内的怪物就打，不会被引到离箱子 32 格以外。
- **跟随防御**：跟着领主，保持大约 4 格。领主打过的目标，士兵会帮着打。
- **跟随进攻**：跟着领主，并主动打领主身边大约 7 格内的怪物。

领主不在线，或在另一个维度，跟随的士兵停在原地。

休整和巡逻时，箱子 12 格内出现怪物会暂时放下手里的事去处理。苦力怕不算。跟随时不因为箱子旁边有怪而跑回来。

### 战斗

近战用剑、斧或矛。远程只用弓，不用弩。自由选择时，4 格以外用弓，靠近了改近战。锁死远程时，怪物走进 4 格会后退，退到大约 7 格再射。弓的射程大约 15 格。箭路上有别的生物时会停手，不把箭射出去。

弓有散布。等级越高散布越小，大师仍然会偏。

骑马需要两件事同时成立：指令里开了骑马，而且栓马桩上有一匹玩家驯服、已经装鞍的马。否则走路。骑乘长矛会先冲一次，之后改成普通近战。骑乘弓箭手边退边射。

副手有盾时，两次近战之间会举盾，出手和拉弓时放下。没有盾不影响战斗。

铁傀儡始终是友方。士兵不打铁傀儡，铁傀儡也不因士兵的伤害还手。苦力怕平时不打；领主已经打过它、而且士兵拿着弓时，才会帮忙射。

### 等级

杀死怪物获得少量村民经验，沿用原版村民的等级：新手、学徒、老手、专家、大师。每高一级，近战伤害 +1，生命 +1 心，攻击间隔少 1 刻（大约 0.05 秒）。新手大约一秒一刀，大师仍然接近这个节奏。

士兵死亡时掉落身上的东西，不会变回村民，也不会变成僵尸村民。挖掉士兵箱子时，他下马，掉落装备和背包，然后消失，并在原地留下一名原来种类的无业村民。

## 构建

需要 JDK 25。

```bash
export JAVA_HOME=/path/to/jdk-25
./gradlew build
```

成品在 `build/libs/trading-golem-1.3.0.jar`。把它和对应版本的 Fabric API 一起放进 `mods` 文件夹。同一文件夹里不要留着旧版本的 jar。
